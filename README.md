# Pejabat Daerah Ranau

Laravel website and CMS for Pejabat Daerah Ranau.

## Deployment

Read [Deployment and preparation guide](README-DEPLOYMENT.md) before configuring a production host. It includes the pre-deployment checklist, environment settings, database/content transfer, persistent uploads, email verification, scheduler, launch checks and rollback.

The `deploy-test` branch is prepared without choosing a hosting provider. Server, managed hosting and Docker requirements are covered; a runnable Docker stack is not included yet.
